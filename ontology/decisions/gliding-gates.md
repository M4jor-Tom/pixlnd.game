# Traversal item 2 — Gliding gates

Require **5 Climbing points**, **at least 1 Hang Gliding point** and a **vendor-bought, equipped
Hang Glider**. Further points improve speed; buying alone is insufficient. Use the existing
single special slot, shared with the [Boat](sailing-gates.md), never an extra slot.
Canonical [skill tree](../domain/3_Classes.md#skill-tree-a).
