# Traversal item 5 — Apply Spikes to remaining cost

Apply Spikes **after** skill reduction: remaining climbing cost **×0.25**, not an added
75 percentage points. Illustratively, **10 → 8 → 2** stamina, **not 0.5**; these are not balance defaults.
Points retain their benefit; Spikes alone never turn positive remaining cost into zero.
This selects no skill-reduction curve/floor or artifact-combination rule.
Canonical [key-item](../domain/3_Classes.md#key-item).
