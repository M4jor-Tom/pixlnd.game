# Assassin item 1 — One Camouflage skill

Camouflage is **one rank-3 skill on key 3**, not a separate ultimate node or key-4 ability.
There is no fourth investment, duplicate purchase, extra charge or separate cooldown/buff.
This is the explicit [D10](skill-tree-columns.md) exception; other specializations and
existing Camouflage effects, duration, cooldown, scaling and stealth/threat behavior stand.
Unlock details remain in the [canonical skill tree](../domain/3_Classes.md#skill-tree-a).
