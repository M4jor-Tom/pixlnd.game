# D11 — Hybrid rules bundle

Blocking gives MP; regeneration means **stamina only**. Lands contain **1–3 artifacts**.
Drop `/pvp`; PvP is a `server.cfg` flag, **off by default**.

[D23](defence.md) supplies block numbers; [D21](class-abilities.md) separately defines mage MP generation.
The [artifact curve](artifact-total-curve.md) does not change the land count.
