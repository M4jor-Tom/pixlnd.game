# Ordinary Lions — untameable

Status: accepted. Owner decision: 2026-10-16. Exact answer: **“2: Approved”**.

Make ordinary Lions **untameable** in the hybrid, retaining hostile jungle/savannah encounters.
This does not change Snow Lions or other cats, food pairings or riding permissions.

Context: historical Lion tameability is disputed; existing null tame data was not itself
prior owner approval. This settles the playable rule without inventing a bait or taming
path. Players retain Lions as enemies, not pets; allowing taming would need a different
approved rule and food choice. Further owner reasoning was not supplied.

Canonical: [creature](../domain/3_Classes.md#creature), with existing
[food-pairing constraints](../domain/5_Constraints.md#5-constraints).
Historical evidence and live JSON remain unchanged. Documentation approval grants no
runtime or validation implementation permission.
