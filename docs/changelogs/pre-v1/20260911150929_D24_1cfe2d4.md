# D24 — Weapon movesets + projectiles (2026-09-11)

Commits: `35c5be0` (ontology), `1cfe2d4` (slice). Section: §3.3 combat (`weapon-type.m1/m2`, `has-moveset`).

## Ontology
- `generators.json#design.movesets`: an M1 / M2 runtime per class weapon-type (`default` fallback, `as` copies), four kinds
  — `melee` (swing-mult, radius-mult, `around`, `lunge`, `finisher`), `projectile` (count, spread, speed, gravity, radius,
  life-s, splash, pierce + tick-s, return), `beam` and `at-cursor` (range, radius) — plus `applies` and `damage-mult`.
- `design.abilities`: new runtime `projectile` (fire-missiles = 4 splash fireballs, bubbles = 6 slow splash shots + heal);
  a dash may `throw` shots first (shuriken-attack throws 5 before the backflip).
- `design.status-effects.poison` (dagger ambush): five ticks of the whole hit over 5 s via the burning runtime.
- `c-moveset-config` (load): keys are weapon-types, kinds / numbers in range, statuses exist, every non-offhand class
  weapon-type has an entry; `c-ability-runtime` extended with the projectile / throw shot rules. `domain.md` §3.3
  weapon-type + ability runtime text, §5 rows, §7 D24; `todo_decide.md` D24; `ontology/README.md` status line.

## Engine (`game/`)
- `combat/projectile.gd`: a Node3D shot that integrates gravity, sweeps a ray along each tick (terrain and bodies),
  damages through `player._strike`, explodes over `splash`, pierces and re-hits every `tick-s`, returns to the shooter at
  half life; a volley shares one attack record so combo / MP count once and the combo resets only when every shot whiffs.
- `entities/player.gd`: `moveset_for`, `aim()` / `eye()` (camera rig direction), `_attack` dispatch (melee sphere with
  spin / lunge / finisher, beam and at-cursor via an aim ray, projectile via `_fire`), `_landed` (combo, finisher counter,
  MP); `_swing` and `_special` route through it, M2 carries the moveset statuses plus the rolled stun.
- `combat/abilities.gd`: `projectile` runtime + dash `throw` through `player._fire`.
- `main.gd`: `godot -- --class=ranger|mage|rogue` picks the starting class (bow / staff / dagger start).
- `combat/test_projectiles.gd` (all green with the rest of the suite): constraint rejections, bow arrow hit + far arc
  whiff + volley, wand beam, staff at-cursor + range, bracelet knockdown ball, fire-missiles, boomerang ticks + return,
  dagger poison + stun, longsword lunge, shuriken throw + backflip, greatsword 3rd-hit knockdown.
