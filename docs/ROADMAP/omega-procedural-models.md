# Omega: procedural bodies, faces & equipment (Ω → follow-up)

**Status:** announced 2023-05-25; devlog posts May–Jun 2023 show it working for undead, zombies,
ogres and all 8 playable races. v1 uses the alpha/1.0 approach: hand-made `.cub` part models
(head, hair, hand, foot, body, tail, shoulder, wing) assembled per `appearance` with per-part
scale/offset/rotation — see `ontology/domain.md#appearance` and `races.json` asset counts.

## Announced features
- "No part of a character is hand-modeled, neither hair, face nor hands": every player, NPC,
  pet and creature is generated by algorithm → unlimited variation.
- **Facial expressions**: neutral, happy/angry, sad, surprised, sleeping, blink (alpha characters
  could not close their eyes; they slept face-down).
- Code snippets shown: undead are always angry; 10 % of male humans are bald.
- **Procedural weapons and armour**: first warrior sets shown 2023-06-13; ogres carry procedurally
  generated wood maces (2023-06-06).
- Undead still needed custom hairstyles (2023-05-26).
- Secondary 2026 report: "procedural races" update alongside a UI overhaul.

## Ontology hooks when picked up
- `appearance` gains a `procedural-seed` and a `body-params` map (proportions, face features,
  hair style/colour params, skin tone) replacing fixed model ids; keep model ids as a fallback
  so hand-made `.cub` assets still load.
- `expression` enum + `entity.mood` driving it (combat → angry, sleeping at inn → sleeping,
  idle → blink cadence).
- `item.appearance-seed` for procedural weapon/armour meshes; `material` and `rarity` feed the
  palette; `weapon-type` fixes silhouette class (blade/haft/head proportions).
- `gen-npc-appearance` becomes a real generator with invariants: race silhouette recognisable,
  gender read from body params, hitbox unchanged (races have no stats — keep it that way).
- Customization bench cubes must still attach: procedural weapon = voxel grid, so `item.upgrades`
  positions remain valid.

## Design notes
- Voxel procedural generation = build a voxel grid from parametric primitives, then mesh; it
  fits the existing `.cub` pipeline (RGB voxels, black = empty).
- Keep the alpha model table (2 552 names) as reference for silhouettes/palettes.
